The mod moves GTA IV's Direct3D 9 device into a separate 64-bit process over shared memory;
the two binaries I build are the client proxy and that server. On behaviour: neither binary
imports any networking library. d3d9.dll imports only GDI32, KERNEL32, USER32, dbghelp and
ole32; NvRemixBridge.exe imports only KERNEL32, SHELL32, USER32, VERSION, dbghelp and ole32.
The upstream tree vendors the Tracy profiler, which does contain socket code, but it is
gated behind the enable_tracy Meson option, that option defaults to false, and the release
build scripts do not set it, so no Tracy code is compiled into the shipped binaries. The mod
writes only inside the game folder and does not inject code into any process other than the
game that loads it.
